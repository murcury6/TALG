# Desk profiles

The small selector at the top of **Desk** switches operating spaces. `+` creates a blank desk, `{ }` edits its whole profile script, and `↻` reloads scripts from the USB. TALG autosaves changed profiles every two seconds and again when the window closes. A purple dot means the latest snapshot was saved; a red dot shows a save error (hover for details).

Profiles live as readable, editable JSON scripts in `work/profiles/<name>.desk.json` on the TALG USB. `work/profiles/active.txt` records which desk opens next. A profile saves the watchlist and selected ticker, canvas viewport, every panel's position and size, its configured view, and any unfinished panel-editor draft. This lets an active chart keep its last applied script while a draft edit is in progress. TALG does **not** serialize Settings credentials, account balances, prices, fetched data, model results, or unsaved code in an Analysis studio editor into a profile. Do not manually paste secrets into a profile script. Saved R indicator/model source files and referenced CSVs remain separate files.

The script is declarative data, not executable Java, R, or Python. `version` must be `1`; `name` must match the filename before `.desk.json`. `watchlist` is an array of uppercase tickers; `selectedTicker` must be one of them or `null`. `viewX`/`viewY` locate the visible canvas. Each item in `panels` has `x`, `y`, `width`, `height`, and an `active` form. You may omit `draft` when it matches `active`; TALG writes both when saving a panel with an unfinished edit. Set `active` to `null` and provide `draft` for a blank, unconfigured panel. An active stock chart's `chartScript` uses the [stock-panel language](PANEL_CONFIGURATION.md); quote panels require a ticker. Panel types are `Portfolio`, `Stock chart`, `Market quote`, `Watchlist`, `Modeling board`, and `Analysis studio`.

For a complete, valid starter with a chart, portfolio overview, and quote panel, see [Research Desk.desk.json](../examples/Research%20Desk.desk.json). It contains configuration only—no prices. Copy it to `work/profiles/Research Desk.desk.json`, click `↻`, and select **Research Desk**. Alternatively, create a profile with `+`, open `{ }`, edit its JSON, and press OK. Invalid scripts are rejected before replacing the current desk; unknown fields and unsupported chart commands are errors. If a script is edited outside TALG while its desk is open, autosave detects the change and stops rather than overwriting it; click `↻` to load it. Reloading explicitly discards unsaved in-memory changes to the selected desk.

This is an operating-space script, not an order strategy or brokerage automation. Panels fetch fresh observed data only after Alpaca is connected. The encrypted credential store is outside the USB and is not embedded in profiles.
